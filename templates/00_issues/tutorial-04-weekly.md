# tutorial-04-weekly

この issue が終わったとき、溜まった wiki を掃除して週の区切りをつける手順を覚えています。

01 済 → 02 済 → 03 済 → **04 いまここ（溜まってから開く）**

これは今日やる issue ではありません。

wiki が空に近いうちに実行しても、壊れたリンクは 1 本も見つからず、アーカイブはほぼ空になります。
何も起きないので、何が便利なのかも分かりません。

しばらく使って page が溜まり、週の終わりに片付けたくなったら開いてください。

これはタスク盤面（`1_issues.md` / `2_done.md`）を使い始めてからの手順です。
終わったら他の 3 本と同じように FIXED にして畳みます。次の週にまたやるなら、その時に自分で issue を切ります。

## 🌧️ Claude への指示

応答は次の 3 段で返してください。

1. 全 step の一覧を 2 行で出す。1 行目が現在地、2 行目が全体。済んだ step に `✓` を付ける

   ```text
   いまここ: ② アーカイブ
   ① 検査 ✓ → ② アーカイブ → ③ 記録 → ④ commit → ⑤ exit
   ```

2. いまの step だけを説明する。先の step は説明しない。表は使わない
3. 末尾を「いまやること: <打つコマンド>」「そうすると: <何が起きるか 1 文>」で締める

最初の応答では、3 段に入る前に、この issue で何をやってどうなるかを 2-3 行で紹介してください。2 回目以降の応答には要りません。

1 回の応答で渡すコマンドは 1 つだけにしてください。次のコマンドを先に見せない。
Claude の応答が返らないローカルコマンドのときは、「終わったら『終わった』と伝えてください」と添えます。
最後の step は `/exit` です。
`/exit` を案内する応答は、この回にやったことと、その結果どう片付いたかの要約から始めてください。検査で何が見つかり、何を週次ファイルに移したかを具体で書きます。
