# 週次アーカイブスキル（sprint review）

`2_done.md` / `1_issues.md` / `0_icebox.md` の完了・確定・廃棄タスクを週次アーカイブに保存し、盤面をリセットする。

## 実行手順

### 1. 週次スパンの計算

今日の日付から「月曜〜日曜」の週次スパンを計算する：

- 月曜日の日付（MMDD形式）
- 日曜日の日付（MMDD形式）
- 年（YYYY）

アーカイブファイルパス: `90_reports/weekly/YYYY/MMDD-MMDD.md`

例: 2026年2月10日（月）〜16日（日）の週 → `90_reports/weekly/2026/0210-0216.md`

### 2. タスクの抽出

以下のタスクを抽出する：

#### `2_done.md` から

- **DONE タスク**: `🌤️ DONE` セクションの全タスク（何も考えず全て移動）
- **FIXED タスク**: `🌈 FIXED` セクションの全タスク（sprint review として週次クリア）
- **FADED タスク**: `🌫️ FADED` セクションの全タスク（何も考えず全て移動）
- インデントされたサブタスクも含める（親タスクとの階層構造を保持）

#### `1_issues.md` から

- **完了タスク**: `☔ WIP` および `🌂 TODO` セクションの `- [x]` で始まる行（パターンマッチで抽出）
- インデントされたサブタスクも含める（親タスクとの階層構造を保持）

#### `0_icebox.md` から

- **FADED タスク**: `🌫️ FADED` セクションがあれば全タスク（通常は存在しない）

### 3. アーカイブファイルへの追記

**重要:** 1週間（月曜〜日曜）で1ファイル。日ごとに区切らず、週のまとめとして追記。

**階層構造の保持:**

- サブタスクをアーカイブする際は、親タスクとの階層構造を必ず保持する
- 親タスクはチェックボックスなし（`- タスク名`）で記録
- サブタスクはインデント付きで `- [x]` または `- [ ]` の形式で記録

**新規作成の場合:**

カテゴリ見出し（H3）は `1_issues.md` / `2_done.md` のカテゴリ見出しをそのまま使う。
タスク行は `[x]` チェック行、issue wikilink + `—` 説明行、親子階層の 3 パターンが混在する（`2_done.md` の FIXED エントリと `1_issues.md` の `[x]` が合流するため）。
FADED セクションは内容がある時だけ出力する。

```markdown
# Week: MMDD - MMDD (Mon - Sun)

## 🌈 DONE (降り終わったもの)

### 🌊 開発

- wiki
  - skill
    - [[commit-skill-design]] — `/lw-commit` skill 設計完了（2026-05-26）
    - [[sync-skill-docs]] — skill 設計ドキュメントと実態のズレ解消（2026-05-30）

### 🏗️ プロジェクト

- [x] プロジェクト A のレビュー完了（2026-05-28）

## 🌫️ FADED (降らなかったもの)

- [[example-issue]] — 別の issue に吸収（2026-05-30）
```

**既存ファイルへの追記:**

weekly 側の既存構造を確認し、適切に追記する。
既存セクション名を尊重し（勝手に変更しない）、同じ意味のセクションがあれば統合する。
対応するセクションがなければ新しいセクション（🌈 DONE、🌫️ FADED）を追加する。
同じタスクは 1 回だけ記録する（重複回避）。

### 4. アーカイブファイルの処理

ファイル `90_reports/weekly/YYYY/MMDD-MMDD.md` を Read。存在すれば Edit で追記、なければ Write で新規作成。

**重要:** Bash で `mkdir` を実行しない。Write が親ディレクトリを自動作成する。

### 5. 盤面のリセット

アーカイブ後、元ファイルをクリアする。

#### `2_done.md` のクリア

- **DONE / FIXED / FADED セクション**: セクションヘッダーと HTML コメントは残し、内容を「（なし）」に置換

#### `1_issues.md` の `[x]` 削除

- **WIP/TODO セクションの `[x]` タスク**: 該当タスクのみ削除（セクション構造は維持）
- サブタスク（インデント付き行）も親の `[x]` と一緒に削除

#### `0_icebox.md` のクリア

- **FADED セクション**がある場合のみ: セクションヘッダーは残し、内容をクリア

**削除時の注意:**

- 該当タスクの行のみを削除
- インデント（サブタスクのスペース2つ等）を崩さない
- 空行やセクション構造は維持
- 周辺の未完了タスクは触らない

ファイル構造は頻繁に変わるため、慎重に削除する。
削除が難しい場合は、該当行のみを削除するシンプルな方法で構わない。

## エラーハンドリング

- `2_done.md` / `1_issues.md` が存在しない → エラーメッセージを表示して終了
- `0_icebox.md` が存在しない → 警告を表示して続行
- アーカイブ対象のタスクが存在しない → 「アーカイブ対象がありません」と表示して正常終了
- 週次ファイルの読み取り失敗 → 新規作成として処理
- Edit/Write 失敗 → エラーを表示(部分的処理でも報告)
