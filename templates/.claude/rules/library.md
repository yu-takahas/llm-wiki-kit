# library

`20_library/` の蔵書管理規約。
書籍の目次 wiki（`20_library/<タイトル>.md`）と目録（`20_library/library.md`）の書き方を定める。
PDF 実体は `20_library/books/` に置き、git には入れない（`.gitignore` 済み）。

目次 wiki は `wiki.md` の schema の対象外。
書誌情報を持つ独自の frontmatter を使う。

## 目次 wiki の frontmatter

```yaml
---
authors: [著者1, 著者2]
translators: [訳者1]
supervisor: 監修者
publisher: 出版社
pages: ページ数
source: ファイル名.pdf
format: 自炊 | 電子書籍
page_offset: 数値 | 章ごとに変動（下記テーブル参照）
tags: [primaryタグ, タグ2, タグ3]
---
```

フィールド順は上記の通り（`authors` → `translators` → `supervisor` → `publisher` → `pages` → `source` → `format` → `page_offset` → `tags`）。

- `authors`: 配列（1 人でも配列）
- `translators`: 翻訳書のみ。日本語オリジナルは省略
- `supervisor`: 監修者がいる場合のみ
- `source`: `20_library/books/` 配下の PDF ファイル名（パスは不要）
- `format`: `自炊`（スキャナ + OCR で自作した PDF）または `電子書籍`
- `page_offset`: PDF の物理ページと本文ページのずれ。`PDF物理ページ = 本文ページ + offset`。本文でページ番号を併記する場合のみ持ち、併記しないなら省略する。
  offset が本全体で一定なら数値で書く。白紙ページのスキップ等で章ごとに変わる本は `章ごとに変動（下記テーブル参照）` と書き、本文に範囲 × offset の表を置く
- `tags`: 1-4 個。先頭が primary tag で、目録のカテゴリ分類に使う。主題が 1 つに収まる本は 1 個でよく、副次タグは検索の役に立つ範囲で足す

## 目次 wiki の本文

- `# <書籍タイトル>`
- 概要 1-2 行（各章の内容が分かる粒度で）
- ページ番号を併記する場合は、概要の直後に `ページ番号の読み方: ...` の 1 行を置き、`page_offset` の検証結果を書く
- 章立て: `## 第N章 タイトル`
- 節リスト: `- セクション名`。章に番号が振られている本は `- 1. セクション名` の形でよい
- サブセクションはインデントで階層化

ページ番号の併記は任意。
併記する場合は `page_offset` を frontmatter に持ち、章は `## 第N章 タイトル（p.12/24）`、節は `- セクション名 ... p.12/24` の形式で書く。
PDF ビューアは物理ページで開くので、本文ページだけでは目的の箇所にジャンプできない。

併記するかしないかは本ごとに選び、1 冊の中で混在させない。
ただし本文ページ番号を持たない前付・序文・索引は `... /PDF物理ページ` の形式で書く。これは混在にあたらないので、その旨を「ページ番号の読み方」の行に書き添える。

本文に「著者 / 出版社」行や `PDF:` 行は書かない（frontmatter で完結させる）。

## 命名

- `.md` ファイル名と `books/` 内の PDF ファイル名を拡張子を除いて一致させる
- 半角スペース禁止、`-` で置換
- `_` 禁止、`-` で置換（prettier の Markdown formatter が単独 `_` を emphasis マーカーと解釈するため。`wiki.md`「文字種規約」と同じ理由）
- `_00` 等のサフィックスやサブタイトルは除去し、短い通称に揃える

## 書籍を追加する手順

1. PDF を `20_library/books/<タイトル>.pdf` に配置する
2. PDF の目次ページを読み取る
3. ページ番号を併記するなら、`page_offset` を head（序盤の本文ページ番号が見えるページ）と tail（末尾数ページ）の両方で検証する。片端だけでは、前付けの丁合いが途中で変わる本でずれを見逃す
4. `20_library/<タイトル>.md` に目次 wiki を作成する
5. `library.md` の該当カテゴリに 1 行追記する

## PDF は Read でなくテキスト抽出して読む

OCR を通した自炊 PDF は透明テキストレイヤーを持つが、Read ツールは画像レイヤーを見るので context を大量に消費する。
`pypdf` でテキストを抽出してテキストとして渡す。

## 目録（`library.md`）

書籍の目次 wiki を作ったら、該当カテゴリに 1 行追記する。
カテゴリ見出しは各書籍 frontmatter の primary tag に対応させる。

行の形式と凡例（`📖` = 電子書籍 / `📄` = 自炊）は `library.md` 自身が記入例として持つ。
