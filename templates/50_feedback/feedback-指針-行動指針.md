# 行動指針

[[feedback-観察-作業スタイル]] と [[feedback-観察-特性プロファイル]] から、skill 設計・Claude の振る舞いに直接効く行動指針を抽出する。
各項目は 5 フィールド（タイトル / 分類 / 状況 / 影響 / 対策）で構造化する。
Claude との作業を重ねる中で、自分に合った指針を育てていく。

## （記入例）推測でなく実物で判断する

- 分類: ワークフロー, エラー対応
- 状況: Claude が推測で設計判断を答える
- 影響: 推測ベースの判断が実態と乖離し、修正を求められる
- 対策: 既存の実物（ファイル・設計書）を Read してから判断する。推測で即断しない

## （記入例）スキップした項目は報告する

- 分類: コミュニケーション, エラー対応
- 状況: タスクの一部をスキップした時に報告せず暗黙に済ませる
- 影響: スキップに気づかず、後で発覚して手戻りになる
- 対策: 作業報告にスキップした項目と理由を含める。スキップ自体は許容される
