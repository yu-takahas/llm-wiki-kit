# wiki のレビュープロファイル

知識管理用の永続 page（`30_wiki/` / `40_project/`）。
成功基準: 3 ヶ月後に文脈を失った状態で読み返しても、単体で内容が理解できること。

## 読み手の定義

将来の自分と将来の Claude。
知識の参照・検索のために読む。
通読ではなく部分参照が主。
書いた時の文脈（セッション・経緯）を共有していない前提。

## 骨格

- 論理の流れ: セクション間の依存関係が順序に反映されているか。読者が前から読んで迷子にならないか [confirmed]
- 軸の分離: 異なる関心軸（例: 機構説明 vs 執筆原則）が交互に出現して流れを分断していないか [confirmed]
- 分量バランス: 特定セクションだけ異常に長い/短いことで粒度のばらつきがないか [confirmed]

## 中身

- 自己完結性: 他 page を読まずに「これは何か」「なぜ重要か」が分かるか [confirmed]
- タイトルと内容の一致: タイトルから期待される範囲と実際の内容にずれがないか [confirmed]
- 来歴・時系列の混入: 判断の理由（why）は残し、経緯（いつ何を経てこうなったか）が混入していないか [confirmed]
- 重複: 同じ知識が別 page に書かれていないか。
  重複があれば正規版に統合し `[[link]]` で参照 [confirmed]
- 数値の時点明記: 複数ソースの数値・統計を併記する場合、各数値の時点が明記され、時点の異なるデータを同列比較していないか [seed]

## 文章

- 曖昧な指示語: 「これ」「それ」が指す対象が一意に定まるか [confirmed]
- 主語の欠落: 省略された主語が、文脈を失った読者にも復元可能か [confirmed]
- 根拠のないぼかし: 「重要である」「一般的に」等の裏付けなき評価語がないか [confirmed]
- 口語的な比喩: 「腐る」「空振りする」「痩せる」「濁す」等で説明せず、何が起きるか（参照が解決しない / 該当なしで終わる / 実態と乖離する）を書けているか [confirmed]

## 表記

- `[[link]]` 先が実在するか（broken link） [confirmed]
- 孤立していないか: 他 page からこの page への `[[link]]` があるか、`index.md` に登録されているか [seed]
- 同一概念への言及が正規 page タイトルの `[[link]]` に統一されているか（日本語訳 / 英語名の混在） [confirmed]
- frontmatter の整合: type / tags / sources / created / updated が規約通りか [confirmed]
