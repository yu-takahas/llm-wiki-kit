# ユーザーの作業スタイル

user が Claude Code と作業する時の振る舞いパターンを観察・蓄積する page。
台帳（issue tracker）として運用し、項目 = issue、日付付き事例行 = 発生記録として蓄積する。
棚卸しフェーズで対策先を判断する（対策先の階層は `$KIT/docs/knowledge/Claude-Codeのメモリ階層.md` を参照）。

## 追記ルール（蓄積ステップ向け）

1. `grep -n "^#### " 50_feedback/feedback-観察-作業スタイル.md` で項目一覧を出す
2. 明確に一致する既存項目がある → その項目 block の末尾に `- 事例 YYYY-MM-DD: <何があった → どうしたか 1 行> [[関連 issue / page]]（🪣 YYYY/MM/DD HH:MM）` を追記する（link は任意、あれば付ける。issue link には経緯の日時を添えて辿りやすくする）
3. 新規、または一致判断に迷う → INBOX に `#### 仮: <タイトル>` + 事例行 1 行で投入する
4. 追記で触ってよいのは事例行の追加だけ。タイトル・本文・対策先行の編集、項目の統合・削除は棚卸しの仕事
5. 対策先行を新設する時は設定日を付与する: `- 対策先: [<種別>] <補足>（YYYY-MM-DD 設定）`。設定日なし = 全事例を対策前とみなす

追記例（既存項目への再発追記、block 末尾に 1 行足すだけ）:

```markdown
#### 例: 項目タイトル

- 対策先: `[memory]` `feedback-example`

項目の本文説明。

- 事例 2026-07-11: 何があった → どうしたか [[関連 page]]（🪣 2026/07/11 23:41）
```
