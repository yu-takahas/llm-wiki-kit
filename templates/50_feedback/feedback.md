# feedback

レビュー知見・ユーザーの特性・作業スタイル等、フィードバック全般の蓄積先。
1 つのフィードバックループ（観察→知見→指針→観察...）の全フェーズをこのフォルダに集約する。

## 命名規則

`feedback-<種別>-<名前>.md`。種別は 4 つ:

| 種別         | 役割                       | いつ読むか            | いつ書くか               |
| ------------ | -------------------------- | --------------------- | ------------------------ |
| 観察         | retro が貯める原料         | retro 時              | retro が追記             |
| 知見         | レビューで使う指摘集       | レビュー skill 起動時 | fix-review が追記        |
| プロファイル | 文書種別のレビュー基準     | doc-review 起動時     | 蓄積で追加               |
| 指針         | 観察から抽出した行動ルール | セッション開始時      | 観察の蓄積から定期再合成 |
