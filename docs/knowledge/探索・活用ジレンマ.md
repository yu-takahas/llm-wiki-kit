# 探索・活用ジレンマ

探索・活用ジレンマ（exploration-exploitation dilemma）は、既知の選択肢から報酬を得る「活用（exploitation）」と、未知の選択肢を試して情報を得る「探索（exploration）」のどちらに資源を割くかという、逐次的意思決定の根本トレードオフ。
強化学習と [[多腕バンディット問題]] の中心課題として知られる。

## ジレンマの構造

ある時点でエージェントが持つ環境の知識は常に部分的なので、手持ちの知識を活用して目先の報酬を取るか、未知の行動を探索してより大きな報酬の可能性に賭けるかのジレンマが生じる。
どちらに振り切っても性能は劣化する。
探索しすぎると劣る行動に時間を浪費し、活用しすぎると更に良い選択肢を取り逃して局所最適に固着する。

概念自体は強化学習に閉じず、経営学の組織学習論（March 1991 の exploration と exploitation の対比）でも使われる分野横断的な抽象概念。

## 代表的な戦略

- ε-greedy: 基本は既知の最善手を選び、確率 ε でランダムに別の手を試す
- UCB（Upper Confidence Bound）: 期待報酬と不確実性の両方を考慮し、不確実性の高い選択肢にボーナスを与える
- Thompson sampling: 事後分布からサンプリングして確率的に探索と活用を両立する

古典フレームは [[多腕バンディット問題]]。

## LLM の決定への関わり

LLM では 3 つの層でこのトレードオフが現れる。

### decoding（推論時）

サンプリング温度 Temperature が出力分布のエントロピーを変えることで、探索・活用を直接制御する。
温度を上げると分布が平坦化して多様な（探索的な）トークンが出やすく、下げると最尤トークンに集中して活用的になる。
近年は温度を固定ハイパラでなく、隠れ状態から適応的に選ぶ研究が進む。

### RL ポストトレーニング

RLHF や検証可能報酬による強化学習で学習が進むと、温度を上げても性能（pass@n）が上がらなくなる「探索の崩壊（exploration collapse）」が起きうる。
分布が尖りすぎて、温度を上げても本質的に新しい候補が出てこなくなる現象。
深さ条件つき decoding でエントロピー最大の構成を探索候補に選ぶ Latent Exploration Decoding や、advantage とエントロピーで出力を重みづけする手法などが、探索を取り戻す対策として研究されている。

### 意思決定エージェント

LLM を contextual bandit のような逐次意思決定にそのまま使うと、古典的バンディットアルゴリズムと比べて探索が不足しがちと報告されている。
観測される失敗モードは、十分な情報収集なしに一見最適な選択肢を繰り返し選ぶ greedy 挙動。
含意は「LLM は放っておくと活用に倒れるので、探索は明示的な足場で外付けする必要がある」。

共通する構図は、RL で鍛えるほど活用に倒れ、探索は意図的に仕掛けないと起きない、という非対称性。
