# スケーリング則

モデルのパラメータ数・学習データ量・計算量（FLOPs）の 3 要素をセットで増やすと、モデルの性能（損失）がべき乗則に従って予測可能に改善し続けるという経験則。
OpenAI の研究者らが GPT 系列の実験から定式化した。

## 概要

スケーリング則の核心は「デカくすれば賢くなる」という経験的事実を定量的に示した点にある。
モデルサイズ・データ量・計算量という 3 要素を単独ではなくセットで比例拡大することが重要で、どれか一つだけを増やしても効果は飽和する。
スケーリング則の原典は OpenAI の Kaplan ら（2020 年）による「Scaling Laws for Neural Language Models」で、この 3 要素と損失の関係をべき乗則として実験的に示した。

このべき乗則に従った性能向上は、従来の機械学習では見られなかった「設計前から改善曲線を予測できる」という特性をもたらし、AI 研究の投資・開発計画を根拠付ける理論的な柱となった。

## 相転移との関係

スケーリング則は性能の漸進的な向上を記述するが、特定の規模閾値を超えたときに新能力が突発的に現れる創発とは区別される。
スケーリング則は「より良くなる」を予測するが、「いつ、どの能力が生まれるか」は予測しない。

## 代表的な示唆

- Chinchilla の法則: DeepMind の研究（2022 年）は、同じ計算予算であればモデルサイズと学習トークン数を均等に拡大するのが最適と示した。最適比率は D ≈ 20N（トークン数 ≈ パラメータ数の 20 倍）
- GPT-3 への応用: スケーリング則を根拠に 1750 億パラメータという当時最大規模の実験が正当化された
- Chinchilla 超過の合理性: Llama 3 70B は D/N ≈ 200 で意図的に超過。学習は一度だが推論は何千億回呼ばれるため、小さいモデルにたっぷり学習させる方が運用コスト全体では経済的
