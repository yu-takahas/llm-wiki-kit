# 多腕バンディット問題

多腕バンディット問題（multi-armed bandit, MAB）は、報酬が不確実な複数の選択肢（腕）から繰り返し 1 つを選び、累積報酬を最大化する逐次的意思決定の枠組み。
[[探索・活用ジレンマ]] の古典的な例として知られる。

## 問題設定

スロットマシン（one-armed bandit）が複数並んでいて、各台の当たりやすさは未知という状況を想像する。
プレイヤーは試行を重ねながら、報酬の高そうな台を引き続ける（活用）か、まだ十分に試していない台を引いて期待値を見積もる（探索）かを毎回選ぶ。
各腕の報酬分布が固定の基本形のほか、文脈（状態）に応じて報酬が変わる contextual bandit などの拡張がある。

## 代表的な解法

- ε-greedy: 確率 1-ε で現状ベストの腕、確率 ε でランダムな腕を選ぶ
- UCB（Upper Confidence Bound）: 期待報酬に不確実性ボーナスを足し、試行回数の少ない腕を優先的に試す
- Thompson sampling: 各腕の報酬の事後分布からサンプリングし、最大値の腕を選ぶ確率的手法
