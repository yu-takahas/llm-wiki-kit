# チェーホフの銃の誤謬

Chekhov's Gun。19 世紀末ロシアの劇作家 Anton Chekhov による脚本原則「劇中に銃を出したら必ず撃たなければならない」を、プロンプト設計に応用したもの。

## 原則

プロンプトに含めた要素は LLM に「伏線」として扱われる。
不要な情報を入れると、モデルがそれを使おうとして混乱や逸脱を生む。

## 適用例

NG: 「あなたは経験豊富なシェフです。趣味は登山です。料理の作り方を教えてください。」
→ 登山が不要な伏線になり、料理に登山の比喩が混入する恐れ。

OK: 「あなたは経験豊富なシェフです。料理の作り方を教えてください。」
