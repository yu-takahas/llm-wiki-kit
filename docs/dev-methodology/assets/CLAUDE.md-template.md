## 開発ワークフロー

- 実装 TODO に着手するなら `/lw-tdd` を使う。config / typo / style だけの変更なら不要
- テストを通すためにテスト自体を削除・コメントアウト・skip しない
- リファクタと機能追加を混ぜない（別 commit にする）
- カバレッジ: 80% 必須、90% 以上推奨。外部 API 依存（LLM 等）のテストは除外可
- commit 前の組み込み skill: /simplify → /code-review → /verify の順

## コミット規約

- `type: 説明` 形式
- type: `feat` / `fix` / `refactor` / `chore` / `docs` / `test`
- このリポジトリへの commit はこの規約に従う
